# Scoped design review

**Mode:** build, review or refine. **Build:** exact source revision or artifact.
**Intent:** audience, primary task, expected focus, system, confirmed constraints.
**Assumptions:** unresolved inferences.

| Inspected surface | Route | Viewport | State | Evidence |
| --- | --- | --- | --- | --- |
| Name | Path | Width x height | Default/focus/error/etc. | Screenshot, trace, checks |

**Excluded / missing:** name each uninspected surface or required check.

| Dimension | Assessment | Basis |
| --- | --- | --- |
| Correctness | Pass / fail / unverified | Applicable checks and observed interactions |
| Coherence | Pass / fail / unverified | Tokens/components/patterns plus rendered comparison |
| Taste | Acceptable / needs refinement / unreviewed | Contextual composition critique |

For each finding:

- Evidence and location: the actual surface/state and supporting artifact.
- Nature: measured fact or visual judgment.
- Observation: what is visible or reproducible.
- Consequence: how this affects the user's task or agreed requirement.
- Recommendation: the smallest fitting correction.
- Verification: what to observe/check after the correction.
- Severity: blocker with demonstrated task/requirement impact, or advisory.

**Outcome:** pass, findings, fail or partial, limited to the scope above.
**Evaluator:** identity and whether this was self-review or independent review.
**Confidence and limits:** uncertainties, environmental differences and missing
user evidence. Do not translate a visual opinion into a numerical certainty.
