# Behavioral calibration

The browser suite produces mechanically valid a, b, c and d alternatives, a
mobile view, an interaction state and seeded geometry defects. These are synthetic
fixtures, not a finished product or a validated visual baseline. Different
hierarchies can pass the same automated checks.

Give an evaluator the skill, cases.json and the corresponding screenshots from
the CI artifact. Withhold expected-findings.json and prior conclusions. See
[calibration.md](../skills/ui-design-judgment/references/calibration.md) for the
evaluation procedure. Record actual evaluator output and adjudicate evidence,
misses, false positives, authority and uncertainty.

Current independent model evaluation: **pending**. Automated tests establish the
evidence adapter and report safeguards. They do not establish general agent taste.

See the [rendered implementation self-review](self-review-2026-10-12.md) for actual
committed screenshots, contextual findings and a partial evidence-backed report.
